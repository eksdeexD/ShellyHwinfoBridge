# cybenetics-import (planned)

Planned for milestone 2. No code yet.

A maintainer tool that takes a Cybenetics report PDF (downloaded manually) and produces one `psu-database.json`
entry by parsing the light-load (20/40/60/80 W) and 10–110 % load tables for both 115 V and 230 V. Every entry
keeps its source attribution and the link to the original report. There is no bulk scraping of the Cybenetics
site.
